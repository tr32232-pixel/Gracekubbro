# E-PORTFOLIO | THANWA INTHAWIMON

### Digital Portfolio & Personal Branding Platform

เว็บไซต์แฟ้มสะสมผลงานดิจิทัล (Electronic Portfolio) ที่พัฒนาขึ้นเพื่อรวบรวมประวัติส่วนตัว ความสามารถ ประสบการณ์ กิจกรรม และผลงานทางวิชาการในรูปแบบออนไลน์ โดยมุ่งเน้นการนำเสนออัตลักษณ์และศักยภาพของผู้จัดทำผ่านเทคโนโลยีเว็บไซต์สมัยใหม่

---

## 1. Project Overview

โครงการนี้เป็นการพัฒนาเว็บไซต์ E-Portfolio เพื่อประยุกต์ใช้เทคโนโลยีดิจิทัลในการนำเสนอข้อมูลส่วนบุคคลอย่างเป็นระบบ โดยออกแบบให้ผู้เข้าชมสามารถเข้าถึงข้อมูลสำคัญได้อย่างสะดวก รวดเร็ว และมีประสิทธิภาพ

เว็บไซต์มีแนวคิดหลักในการสร้าง Personal Branding ผ่านการนำเสนอความสามารถ ความสนใจ และประสบการณ์ที่สะท้อนถึงศักยภาพด้านการเรียนรู้ การคิดวิเคราะห์ การสร้างสรรค์ และแนวคิดการเป็นผู้ประกอบการ

## 2. Objectives

1. พัฒนาทักษะด้านเทคโนโลยีและการสร้างเว็บไซต์
2. จัดระบบข้อมูลและผลงานให้อยู่ในรูปแบบดิจิทัล
3. สร้างภาพลักษณ์และอัตลักษณ์ส่วนบุคคลผ่าน Personal Branding
4. นำเสนอศักยภาพและความพร้อมในการศึกษาต่อระดับอุดมศึกษา
5. ประยุกต์ใช้เทคโนโลยีเพื่อเพิ่มประสิทธิภาพในการสื่อสารและนำเสนอข้อมูล

## 3. Design Principles

การออกแบบเว็บไซต์ยึดหลักการสำคัญ 4 ประการ

- **User-Centered Design:** ออกแบบโดยคำนึงถึงประสบการณ์และความต้องการของผู้ใช้งาน
- **Visual Hierarchy:** จัดลำดับความสำคัญของข้อมูลเพื่อให้ผู้เข้าชมเข้าใจเนื้อหาได้ง่าย
- **Responsive Design:** รองรับการแสดงผลบนคอมพิวเตอร์ แท็บเล็ต และสมาร์ตโฟน
- **Consistency:** ควบคุมรูปแบบ สี ตัวอักษร และองค์ประกอบต่าง ๆ ให้มีความสอดคล้องกัน

## 4. Color Identity

กำหนดอัตลักษณ์ของเว็บไซต์ด้วยแนวคิด Modern Business

| สี | รหัสสี | ความหมาย |
|---|---|---|
| Deep Red | #B5121B | ความมุ่งมั่นและภาวะผู้นำ |
| Golden Yellow | #F4C542 | ความสำเร็จและโอกาส |
| White | #FFFFFF | ความเรียบง่ายและน่าเชื่อถือ |
| Dark Gray | #222222 | ความเป็นมืออาชีพ |

## 5. Technologies & Tools

เทคโนโลยีที่ใช้ในการพัฒนาเว็บไซต์

- HTML5 — โครงสร้างและองค์ประกอบของเว็บไซต์
- CSS3 — การออกแบบและจัดรูปแบบส่วนติดต่อผู้ใช้
- JavaScript — การจัดการการทำงานและเพิ่มปฏิสัมพันธ์
- Visual Studio Code — เครื่องมือสำหรับพัฒนาและจัดการซอร์สโค้ด
- GitHub — ระบบจัดเก็บและควบคุมเวอร์ชันของโปรเจกต์
- GitHub Pages — แพลตฟอร์มเผยแพร่เว็บไซต์

## 6. Website Architecture

เว็บไซต์แบ่งออกเป็นส่วนสำคัญดังนี้

1. Home — หน้าแรกและการแนะนำตัว
2. About Me — ประวัติส่วนตัวและอัตลักษณ์
3. Education — ประวัติการศึกษา
4. Skills — ความสามารถและทักษะ
5. Activities — กิจกรรมและประสบการณ์
6. Certificates — เกียรติบัตรและผลงาน
7. Future Goals — วิสัยทัศน์และเป้าหมายในอนาคต
8. Contact — ช่องทางการติดต่อ

## 7. Development Methodology

กระบวนการพัฒนาเว็บไซต์ประกอบด้วย 5 ขั้นตอน

1. Planning & Analysis — วิเคราะห์วัตถุประสงค์และกำหนดขอบเขตของระบบ
2. UI/UX Design — ออกแบบโครงสร้างและประสบการณ์ผู้ใช้งาน
3. Development — พัฒนาเว็บไซต์ด้วย HTML, CSS และ JavaScript
4. Testing & Evaluation — ตรวจสอบการทำงาน ความถูกต้อง และความเข้ากันได้ของอุปกรณ์
5. Deployment — เผยแพร่เว็บไซต์ผ่าน GitHub Pages

## 8. Expected Outcomes

- ได้เว็บไซต์ Portfolio ที่สามารถเข้าถึงได้ผ่านอินเทอร์เน็ต
- สามารถนำเสนอข้อมูลและผลงานได้อย่างเป็นระบบ
- พัฒนาความรู้ด้านการออกแบบและพัฒนาเว็บไซต์
- สร้างทักษะการประยุกต์ใช้เทคโนโลยีดิจิทัล
- มีผลงานดิจิทัลสำหรับประกอบการสมัครเข้าศึกษาต่อระดับมหาวิทยาลัย

## 9. Future Development

แนวทางการพัฒนาในอนาคต ได้แก่

- เพิ่มระบบจัดการรูปภาพและเกียรติบัตร
- พัฒนาระบบแสดงผลงานแบบ Interactive Gallery
- เพิ่มประสิทธิภาพการเข้าถึงเว็บไซต์ (Web Accessibility)
- ปรับปรุงประสิทธิภาพการโหลดหน้าเว็บไซต์
- พัฒนาระบบดาวน์โหลด Portfolio ในรูปแบบ PDF
